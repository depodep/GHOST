GHOST ESP8266 Pin Map

Board: NodeMCU / Wemos D1 Mini

                     ESP8266 MODULE
                 +----------------------+
                 | 3V3  -------------> DHT22 VCC
                 | GND  -------------> DHT22 GND
                 | D3   -------------> DHT22 DATA
                 |                      |
                 | D4/GPIO2 ----------> Heater 1 relay
                 | D5/GPIO14 ---------> Heater 2 relay
                 | D6/GPIO12 ---------> Heater fan relay
                 | D7/GPIO13 ---------> Egg swing relay
                 | D8/GPIO15 ---------> Exhaust relay
                 |                      |
                 | GND  -------------> Relay board GND
                 | 5V   -------------> Relay board VCC
                 +----------------------+

Boot-safe notes:
- D8/GPIO15 must stay LOW during boot.
- D4/GPIO2 must be HIGH during boot.
- If the relay board pulls either pin the wrong way at power-up, the ESP8266 may not boot and serial output may stop.
- If you get no serial response when the relay board is connected, test with relay VCC removed first, then reconnect with a separate 5V supply and common GND.
